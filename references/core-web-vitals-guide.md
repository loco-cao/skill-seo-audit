# Core Web Vitals Guide

> 供 `seo-core-web-vitals-expert` 执行审计时参考。

---

## 角色定位

验证页面的核心网页指标是否达到 Google 推荐阈值。Core Web Vitals 是 Google 于 2021 年正式纳入排名因素的页面体验信号，直接影响搜索排名和用户体验。

---

## 排名因素关联

- **页面体验 / Core Web Vitals**（Tier 1，第 4 位）：正式纳入排名因素；移动端体验全面优先
- **页面加载速度**（Tier 3）：超出 CWV 的部分，越快越好

---

## Core Web Vitals 三指标

### 1. LCP（Largest Contentful Paint）

- **定义**：视口中最大内容元素的渲染时间
- **目标值**：**< 2.5 秒**
- **测量方式**：
  - 远程模式：通过 TTFB + 渲染阻塞资源推断
  - 本地模式：检查构建配置中的代码分割、资源预加载
- **优化方向**：
  - 优化服务器响应时间
  - 预加载 LCP 元素（`<link rel="preload">`）
  - 压缩图片/使用现代格式
  - 移除阻塞渲染的 CSS/JS

### 2. INP（Interaction to Next Paint）

- **定义**：用户交互后到页面下一次绘制的时间（取代 FID）
- **目标值**：**< 200 毫秒**
- **测量方式**：
  - 远程模式：通过 JS 执行时间推断
  - 本地模式：检查事件处理器复杂度、长任务（>50ms）
- **优化方向**：
  - 减少主线程长任务
  - 使用 Web Workers 处理复杂计算
  - 优化事件监听器（防抖/节流）

### 3. CLS（Cumulative Layout Shift）

- **定义**：页面生命周期内所有意外布局偏移的累积
- **目标值**：**< 0.1**
- **测量方式**：
  - 远程模式：检查图片/iframe 是否有尺寸声明
  - 本地模式：检查动态注入内容的容器是否有预留空间
- **优化方向**：
  - 图片和 iframe 设置 width/height 属性
  - 使用 CSS `aspect-ratio` 预留空间
  - 避免在已有内容上方插入动态内容
  - 字体加载策略优化（避免 FOIT/FOUT）

---

## 辅助指标

### TTFB（Time to First Byte）

- **目标值**：**< 600 毫秒**
- 影响因素：服务器性能、CDN、缓存策略、数据库查询效率

### FCP（First Contentful Paint）

- 第一个文本或图片元素渲染的时间
- 与 LCP 协同评估首屏加载体验

## 评分指南

| 分数 | 等级 | 说明 |
|------|------|------|
| 90–100 | 优秀 | LCP < 2.5s、INP < 200ms、CLS < 0.1、TTFB < 600ms |
| 70–89 | 良好 | 1-2 个指标略超标（如 LCP 2.5-4s、CLS 0.1-0.25） |
| 60–69 | 有风险 | 多个指标超标（如 LCP > 4s、CLS > 0.25） |
| 0–59 | 严重 | 所有指标严重超标、页面几乎无法使用 |

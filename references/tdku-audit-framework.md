# TDKU审计框架指南

## TDKU概念

TDKU = Title + Description + Keywords + URL，四位一体的页面元数据体系。

## 全站TDKU一致性检查方法

### 批量抓取
1. 使用爬虫抓取全站所有可索引页面的Title、Description、URL
2. 或使用GSC导出、Sitebulb/Screaming Frog扫描
3. 数据量：小型站（<1k页面）全量，中大型站抽样+核心页面全量

### 一致性矩阵

| 页面类型 | Title模板 | Description模板 | URL模式 | H1模式 |
|----------|-----------|-----------------|---------|--------|
| 首页 | 品牌名 | 品牌价值主张 | / | 品牌名+定位 |
| 产品页 | 产品名 | 产品价值+CTA | /product/xxx | 产品名 |
| 分类页 | 分类名 | 分类描述 | /category/xxx | 分类名 |
| 博客页 | 文章标题 | 文章摘要 | /blog/xxx | 文章标题 |
| 关于页 | 关于我们 | 品牌故事 | /about | 关于[品牌名] |

## Title审计清单

### 基础合规
- [ ] 每页有且仅有一个<title>
- [ ] 长度≤60字符（中文≤30字）
- [ ] 全站唯一，无重复
- [ ] 无关键词堆砌（同一词无意义重复>2次）

### SEO优化
- [ ] 核心关键词出现在前20字符
- [ ] 品牌名统一追加格式（`| 品牌`或`- 品牌`）
- [ ] 与H1互补而非完全重复
- [ ] 与页面内容主题匹配

### 技术检查
- [ ] 服务端HTML中可找到（非JS动态注入）
- [ ] 分页Title区分（`第2页`或`Page 2`）
- [ ] 无HTML实体未解码（如`&amp;`应显示为&）

## Meta Description审计清单

### 基础合规
- [ ] 每页有唯一的meta description
- [ ] 长度120-160字符（中文60-80字）
- [ ] 全站唯一，无重复
- [ ] 完整句子，非关键词列表

### 优化检查
- [ ] 包含至少一个核心关键词
- [ ] 包含行动号召（CTA）或价值主张
- [ ] 吸引点击（有数字、疑问、利益点）
- [ ] 与搜索意图匹配

### CTR修复场景
- 展现量>1000且CTR<2% → 优先优化Description
- 展现量>100且CTR<1% → 检查Title与Description相关性
- 排名≥3但CTR低于行业均值 → 优化Snippet吸引力

## URL审计清单

### 基础合规
- [ ] URL语义化，包含目标关键词
- [ ] 层级≤4层，核心页面≤3层
- [ ] 全站唯一，同一内容无多URL
- [ ] 无无意义参数（Session ID、跟踪参数未canonical）

### 技术检查
- [ ] 返回200状态码
- [ ] 有自引用canonical
- [ ] 大小写统一（建议全小写）
- [ ] 尾斜杠统一

## TDKU与搜索意图匹配度评估

| 搜索意图 | Title特征 | Description特征 | URL特征 |
|----------|-----------|-----------------|---------|
| 信息型 | 含"如何""指南""什么是" | 承诺提供答案 | /blog/ /guide/ |
| 交易型 | 含"购买""价格""优惠" | 突出价格/促销 | /buy/ /shop/ |
| 导航型 | 品牌名+页面类型 | 简洁定位 | /about/ /contact/ |
| 商业调查 | 含"最佳""对比""评测" | 客观对比承诺 | /compare/ /reviews/ |

## TDKU评分标准

| 检查项 | 分值 | 扣分规则 |
|--------|------|----------|
| Title存在且唯一 | 15 | 缺失-15，重复每个-5 |
| Title长度合规 | 10 | 超长-5，过短-3 |
| Title关键词前置 | 10 | 未前置-10 |
| Description存在且唯一 | 15 | 缺失-15，重复每个-5 |
| Description长度合规 | 10 | 超长/过短各-5 |
| Description含CTA | 10 | 无CTA-10 |
| URL语义化 | 15 | 无意义URL每个-5 |
| URL层级合规 | 10 | 超4层每个-3 |
| TDKU一致性 | 5 | 风格混乱-5 |

满分100，≥90优秀，80-89良好，70-79需改进，<70不合格

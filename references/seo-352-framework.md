# SEO 352黄金法则评估框架

## 框架概述

352 = 3大核心要素 + 5维优化检查 + 2条底线原则

适用于快速评估和全面审计两个场景。

---

## 3大核心要素审计

### 要素1：TDK设置合规性
- Title唯一性、长度、关键词位置
- Description唯一性、长度、CTR吸引力
- Canonical正确配置
- 全站TDKU一致性

**评分权重**：30%（核心要素中最重要）
**否决项**：全站无Title或全站Title重复 → 该要素直接不合格

### 要素2：内容质量
- 原创度（无采集、无机器翻译）
- 深度（与竞品对比的信息增益）
- 搜索意图匹配度
- EEAT信号（经验、专业性、权威性、可信度）
- 更新频率与内容新鲜度

**评分权重**：40%（内容为王）
**否决项**：大量采集内容或doorway pages → 该要素直接不合格

### 要素3：外链健康度
- 引用域数量与质量
- 锚文本分布自然度
- Toxic外链比例
- 外链获取速度合理性
- 品牌建设监测

**评分权重**：30%
**否决项**：大量购买外链或参与PBN → 该要素直接不合格

---

## 5维优化检查

### 维1：技术SEO（权重30%）
- 索引状态（覆盖率、noindex误用）
- 可抓取性（robots.txt、sitemap、死链）
- 网站架构（URL层级、内链、面包屑）
- 规范化（canonical、重复内容、hreflang）
- 渲染（JS渲染、SSR/SSG配置）

### 维2：On-Page SEO（权重20%）
- TDKU设置
- H标签层级
- 图片Alt与优化
- 内链布局
- Schema结构化数据

### 维3：内容SEO（权重25%）
- 原创度与深度
- 搜索意图匹配
- 关键词布局（密度、TF-IDF、LSI）
- 内容更新机制
- Thin Content检测

### 维4：外链SEO（权重15%）
- 外链质量评估
- 锚文本多样性
- 外链建设渠道
- Toxic外链清理
- 品牌建设

### 维5：用户体验（权重10%）
- Core Web Vitals（LCP/INP/CLS）
- 移动端可用性
- 页面交互与导航
- 内容可读性
- 转化路径

---

## 2条底线原则

### 原则1：白帽合规
- 禁止购买外链或参与链接交换计划
- 禁止关键词堆砌（隐藏文本、 doorway pages）
- 禁止Cloaking（向用户和爬虫展示不同内容）
- 禁止采集/抄袭内容
- 禁止使用PBN（Private Blog Network）
- **违反原则1 → 一票否决，总分最高不超过50分**

### 原则2：用户价值优先
- 内容首要解决用户问题，非为搜索引擎而写
- 页面设计以用户易用为优先
- 广告与弹窗不得干扰核心内容阅读
- 所有技术优化最终服务于用户体验
- **违反原则2 → 标记为高风险，需立即整改**

## 352框架评分计算

### 快速评估版（15分钟）

对每个核心要素打分（0-100）：
- TDK合规性得分 × 0.30
- 内容质量得分 × 0.40
- 外链健康度得分 × 0.30

= 核心要素总分

快速定级：
- ≥90：优秀，维护为主
- 80-89：良好，小修小补
- 70-79：需改进，有明显问题
- <70：不合格，需全面整改

### 全面审计版（深度）

在5维优化检查的每个维度下，按专家评分加权：

```
总分 = 技术SEO×0.30 + On-Page×0.20 + 内容×0.25 + 外链×0.15 + 用户体验×0.10
```

其中各维度分数来自对应专家的评分：
- 技术SEO = (crawlability + indexability + architecture + schema + mobile + security) / 6
- On-Page = (meta + heading + image + tdku) / 4
- 内容 = (content + eeat) / 2
- 外链 = backlink
- 用户体验 = (core-web-vitals + ux) / 2

# 竞品分析指南

## 竞品筛选五条标准

1. **SERP重叠度**：目标关键词前10中反复出现的域名
2. **业务相似度**：直接竞品 > 间接竞品 > 内容竞品
3. **可追赶性**：域名权重与自身差距≤30%（DR差距过大短期难追）
4. **策略参考价值**：有值得学习的内容、技术或外链策略
5. **数量控制**：核心竞品3-5个，辅助竞品≤10个

## 六维对比框架

| 维度 | 检查项 | 数据来源 |
|------|--------|----------|
| 技术SEO | 索引量、Core Web Vitals、移动适配、HTTPS、Schema | GSC、PSI、手动检查 |
| 内容覆盖 | 关键词覆盖数、内容深度、更新频率、内容类型 | Ahrefs/SEMrush、SERP分析 |
| 外链Profile | DR、引用域数量、锚文本分布、外链增长速度 | Ahrefs/Moz |
| 用户体验 | 设计质量、页面加载感知、转化路径、交互流畅度 | 手动体验、GTmetrix |
| 品牌信号 | 品牌搜索量、社交存在、提及量、评论数 | Google Trends、社交媒体 |
| EEAT信号 | 作者资质、About页面、信任元素、资质认证 | 手动检查页面 |

## 竞品数据提取清单

### 基础数据
- 域名年龄、DR/DA、预估自然流量
- 索引页面数量（site:domain.com）
- Top 10流量页面（Ahrefs Top Pages）
- 核心关键词排名分布

### 内容差距分析
- 竞品有排名而自身无覆盖的关键词（Content Gap）
- 竞品覆盖的搜索意图类型（信息型/交易型/商业调查型）
- 竞品的内容格式（长文/列表/对比表/视频/工具）
- 竞品的内容更新频率与维护策略

### 技术差距分析
- 竞品使用的Schema类型（自身是否缺失）
- 竞品的页面速度对比
- 竞品的内链结构特点
- 竞品的内容组织方式（分类体系、标签体系）

### 外链差距分析
- 竞品的引用域数量与趋势
- 竞品Top外链来源（Ahrefs Referring Domains）
- 竞品获得外链的内容类型（工具、数据研究、指南）
- 竞品的外链建设渠道（目录、客座博客、PR）

## 机会识别方法论

### 共同优势（行业基准）
- 所有竞品都做对的事 = 必须达到的底线
- 例如：所有竞品都有SoftwareApplication Schema → 自身必须补上

### 差异化空白
- 竞品未覆盖但搜索量存在的长尾关键词
- 竞品未满足的搜索意图（如缺少对比评测内容）
- 竞品未进入的细分领域

### 可复制资源
- 竞品获取外链的渠道列表 → 直接跟进
- 竞品高流量的内容格式 → 模仿并超越
- 竞品的Schema策略 → 应用到自身

### 快速胜利（Quick Wins）
- 低竞争度高价值关键词（KD<20，搜索量>100）
- 现有页面小幅优化即可提升排名的机会
- 技术SEO漏洞修复带来的快速索引提升

## 竞品分析输出格式

```
竞品名称：[域名]
域名权重：DR [X] / 预估流量 [Y]
核心优势：[3点]
核心劣势：[3点]
值得复制的策略：[2-3项]
对我方的威胁等级：High/Medium/Low

内容差距Top 5：
1. [关键词] - [搜索量] - [竞品排名] - [我方现状]
...

技术差距：
- Schema：[竞品有/无] vs [我方有/无]
- 速度：[竞品LCP] vs [我方LCP]
- 移动：[竞品状态] vs [我方状态]
```

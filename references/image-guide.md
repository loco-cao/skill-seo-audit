# Image Optimization Guide

> 供 `seo-image-expert` 执行审计时参考。

---

## 角色定位

验证页面图片是否优化到位，既利于搜索引擎理解图片内容，又不影响页面性能。图片优化直接影响可访问性、Core Web Vitals（CLS）和用户体验。

---

## 排名因素关联

- **图片优化（Alt、压缩、WebP、CLS）**（Tier 3）：影响可访问性和体验
- **页面体验 / Core Web Vitals**（Tier 1，第 4 位）：图片尺寸缺失会导致 CLS 问题
- **可访问性**：alt 文本是无障碍浏览的基础要求

---

## 评估维度

### 1. Alt 文本

- 所有图片是否都有 alt 属性
- alt 文本是否描述性（非"image1"、"photo"）
- 装饰性图片是否使用空 alt（`alt=""`）
- alt 文本是否自然包含关键词（非堆砌）
- alt 文本长度是否适中（建议 < 125 字符）

### 2. 文件名语义化

- 图片文件名是否描述内容（如 `red-sneakers.jpg` 而非 `IMG_1234.jpg`）
- 是否使用小写和连字符分隔
- 是否包含图库照片文件名模式（如 `shutterstock_123`、`istock_456`）—— 图库照片属轻微负面信号

### 3. 图片格式

- 是否使用现代格式（WebP、AVIF）
- 是否仍大规模使用未压缩的 PNG/JPEG
- 是否提供格式回退（picture 标签或 srcset）

### 4. 懒加载

- 首屏以下图片是否使用 `loading="lazy"`
- 首屏图片是否避免懒加载（应即时加载）
- 是否使用原生懒加载或 Intersection Observer

### 5. 尺寸声明与 CLS

- 图片是否有显式的 `width` 和 `height` 属性
- 或通过 CSS `aspect-ratio` 保留空间
- 是否因图片尺寸缺失导致布局偏移（CLS）

### 6. 图片大小

- 单张图片是否过大（建议 < 200KB，首屏图片尤其重要）
- 是否存在未压缩的原图直传
- 是否使用响应式图片（srcset/sizes）适配不同设备

---

## 评分指南

| 分数 | 等级 | 说明 |
|------|------|------|
| 90–100 | 优秀 | 所有图片有描述性 alt、使用 WebP/AVIF、懒加载正确、尺寸声明完整 |
| 70–89 | 良好 | 轻微问题：少数图片缺少 alt、部分未使用现代格式、个别图片过大 |
| 60–69 | 有风险 | 大量图片无 alt、未压缩原图多、无懒加载、首屏图片 > 500KB |
| 0–59 | 严重 | 绝大多数图片无 alt、全站无压缩、图片严重拖慢页面速度、大量图库照片 |
